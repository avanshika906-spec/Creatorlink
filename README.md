# CreatorLink

Beginners helping beginners.

New creators can't afford professional editors, and student editors
can't get hired without experience. CreatorLink connects both sides
so they can grow together.

## Features
- Sign up as a creator or a student editor
- Students add samples of their work to build a portfolio
- Creators post editing jobs and browse student portfolios
- Students apply, creators hire
- Chat between creators and editors
